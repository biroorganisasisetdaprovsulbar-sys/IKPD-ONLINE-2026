# IKPD ONLINE 2026 PRODUCTION

Sistem Informasi Penilaian Indeks Kematangan Perangkat Daerah.

Teknologi:
- React + Vite
- Supabase Authentication
- Supabase PostgreSQL
- Supabase Storage
- Vercel Deployment

Cara menjalankan:
1. npm install
2. copy .env.example menjadi .env
3. isi konfigurasi Supabase
4. npm run dev
